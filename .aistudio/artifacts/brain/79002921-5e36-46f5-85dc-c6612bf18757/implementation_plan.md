# 面接特化型ポートフォリオ＆スキル可視化プレゼンテーションWebアプリ

面接官への画面共有（Screen Share）を想定し、短時間で「論理的な思考力」「即戦力性」「技術スタックの幅と深さ」を明快にプレゼンテーションできるポートフォリオWebアプリケーションを構築します。

### User Review & Critical Decisions

> [!IMPORTANT]
> ユーザー様からの回答に基づき、以下の確定方針で設計・実装を進めます。

- **Confirmed Decision 1（職種ロール）**: 面接先企業の職種や求めるスキルセット（バックエンド、DX/業務改善リード、フロントエンド、フルスタック）に応じて、画面全体の表示データ・実績・スキルチャートがワンクリックで最適化される「マルチロール即時切替機能」を搭載。
- **Confirmed Decision 2（デザインテイスト）**: 洗練されたモダンミニマル（白・黒・スレートのニュートラル基調に、知的なエメラルドグリーン `#10b981` をキースポットとして配置）。ライト／ダークモード切替にも完全対応。
- **Confirmed Decision 3（プレゼン支援機能）**: STAR法（Situation・Task・Action・Result）のアコーディオン開閉に加え、画面共有時に一目で重要数字・成果が伝わる「プレゼン用要点ハイライトモード」および「1ファイルHTMLエクスポート機能」を完備。

---

### 1. Overview & Core Concept

- **What It Does**:
  転職・採用面接の場（オンライン会議の画面共有）で、求職者が自己紹介から実績説明、技術スタックの深掘りまでを1画面で淀みなく説明できるダッシュボード型ポートフォリオ。面接官が質問したくなる論理的な導線（Now → Core Strengths → STAR Projects → History）を提供します。
- **Target Audience / Persona**:
  採用担当者・エンジニアリングマネージャー・VPoE・CTOなど、技術的妥当性とビジネスインパクトを厳格に評価する面接官。
- **Key Value**:
  「何ができるか」だけでなく「なぜその技術を選び、どう課題を解決し、どのような定量的成果をもたらしたか」がSTAR法とChart.jsレーダーチャートにより即座に伝わります。また面接先の募集要件に合わせてプロファイルを即時切り替え可能です。

---

### 2. User Experience & Visual Design

- **Key User Flows**:
  1. **ヒーローセクション（0〜10秒）**: 氏名・肩書・キャッチコピー・経歴年数・専門領域タグ・各種リンク（GitHub, LinkedIn, Wantedly, Zenn/Qiita, Email）を一覧。上部に面接先ロール切替（Backend / DX / Frontend）と画面共有ハイライトスイッチ。
  2. **Nowセクション（10〜30秒）**: 「直近のフォーカス領域・現在進行形のテーマ（例: 大規模APIリプレイス、LLM社内業務自動化）」を明確に打ち出し、学習意欲と現在進行形の即戦力感を提示。
  3. **スキルマップ・強み可視化（30〜60秒）**: Chart.jsによるレーダーチャート（6軸：システム設計、実装力、インフラ/クラウド、要件定義・企画、チームリード・推進力、業務改善・自動化）＋実務レベル別（即戦力/実務経験あり/キャッチアップ中）のスキルタグ一覧。
  4. **STAR実績紹介（60〜180秒）**: Problem（課題）→ Action（施策・技術選定）→ Result（定量成果）の3ステップ構造。重要数字バッジ（「月40h削減」「レスポンスタイム65%改善」等）を目立たせ、アコーディオンで詳細を展開可能。
  5. **職歴タイムライン & クイックデータ編集**: 過去から現在までの簡潔な変遷。さらに自身の情報に書き換えたい場合の「データ編集モーダル」および「単一ファイルHTMLダウンロード/コピー機能」を用意。

- **Visual Identity & Theme**:
  - *Aesthetic Direction*: 洗練されたテックビジネス・モダンミニマル（過度な装飾・不要なバッジ乱用を排除し、タイポグラフィと余白で魅せる知的なUI）。
  - *Color Palette & Mood*:
    - 60% Canvas: クリーンホワイト (`#ffffff`) / ディープスレートダーク (`#0f172a`)
    - 30% Structural: ニュートラルカードサーフェス (`#f8fafc` / `#1e293b`), ヘアラインボーダー (`border-slate-200` / `border-slate-800`)
    - 10% High-Contrast Accent: エメラルドグリーン (`emerald-500` / `#10b981`), シックなフォントカラー (`slate-900` / `slate-100`)
  - *Typography & Hierarchy*:
    - タイトル・見出し: `Plus Jakarta Sans` / `Outfit`
    - 本文・STAR解説: `Plus Jakarta Sans` / 日本語高品位フォントシステム
    - 数値・メトリクス: `font-mono tabular-nums` で定量的根拠を強調

### 3. Key Product Decisions & Trade-Offs

- **Decision 1: マルチロール切替（Preset Profiles）**:
  - *Chosen Approach*: バックエンド/フルスタック、DX/業務改善、フロントエンドの3つの定義済みプロファイルをワンクリックで切り替え可能にし、レーダーチャートと実績データを連動。
  - *Why*: 転職活動では受ける企業やポジションによって訴求軸が異なるため、面接官の属性に合わせてアピールポイントを即座に最適化できる。
- **Decision 2: 画面共有ハイライト（Screen-Share Focus Mode）**:
  - *Chosen Approach*: 画面共有中にキーとなる定量成果バッジやアクションの要点を視覚的にハイライトし、視線誘導をサポートするトグルを用意。
  - *Why*: 面接官が画面を見たときに、テキストの海に埋もれず、最もアピールしたい数値（30%短縮、月40h削減など）に即座に視線を集中させられる。
- **Decision 3: 単一ファイルHTML（Standalone HTML）の完全出力**:
  - *Chosen Approach*: アプリ内でリッチに動作させつつ、ヘッダーに「単一HTMLを保存/コピー」機能を完備。Tailwind CDN, Chart.js CDN, Lucide CDNを埋め込んだ完全なスタンドアロンコードをクリップボードコピー＆ダウンロード可能にする。
  - *Why*: 要件1（HTML/CSS/JSを1つのファイルにまとめた完全なコード）を100%満たし、オフラインやローカルブラウザ、面接官へのメール添付等でも即座に開ける利便性を提供。

- **Dependencies**:
  - `chart.js`（レーダーチャート描画用）
  - `lucide-react`（アイコン）
  - `@tailwindcss/vite` & Tailwind CSS
- **Interactions**:
  - 職種プリセット切替（アニメーション付きチャート再描画・データ切り替え）
  - STARアコーディオン展開・全開閉トグル
  - プレゼン・ハイライトモード（数値バッジのグローとコントラスト強調）
  - ダークモード・ライトモード切替（永続化）
  - 1ファイルHTML出力モーダル（コード表示、プレビュー、ワンクリックコピー、.htmlダウンロード）
  - プロフィールカスタム編集モーダル（名前や数値を自分の実データにその場で書き換え・即時反映）
